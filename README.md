# بوت موجز الأخبار العالمية على Telegram (تكلفة 0$)

يجمع الأخبار من مصادر عالمية بلغات متعددة، يدمج المكرر، يرتّبها بالصدى، يترجمها ويعيد صياغتها بالعربية، ثم ينشرها في قناة Telegram على دفعات، وآخر دفعة موجز عناوين اليوم. **كل شيء يعمل على GitHub Actions + طبقات مجانية.**

## كيف يعمل

```
كل 10 دقائق (GitHub Actions)
  ├─ يقرأ أوامرك من Telegram
  ├─ يجمع RSS (كل 30 دقيقة) + embeddings متعددة اللغات (Gemini)
  ├─ يجمّع الأخبار المتشابهة في "قصص" ويحسب الصدى
  ├─ هل حان موعد دفعة؟ → تصنيف (سياسة/اقتصاد/تكنولوجيا) → حصص النسب → صياغة عربية → فحص آلي → نشر
  ├─ خبر عاجل؟ (≥5 مصادر + أهمية ≥9) → نشر فوري
  └─ في موعد الموجز: عناوين كل أخبار اليوم المنشورة
```

## الإعداد (15 دقيقة)

1. **بوت Telegram**: كلّم `@BotFather` ← `/newbot` ← احفظ التوكن.
2. **قناة**: أنشئ قناة، وأضف البوت **مشرفاً** بصلاحية "نشر الرسائل".
3. **معرّفك**: كلّم `@userinfobot` لمعرفة رقم حسابك (للتحكم بالأوامر). ثم افتح محادثة مع بوتك وأرسل `/start`.
4. **مفتاح Gemini** مجاني من Google AI Studio (واختيارياً مفتاح Groq كاحتياط).
5. **مستودع GitHub**: ارفع هذا المجلد إلى مستودع **عام (Public)** (الدقائق مجانية بلا حد للمستودعات العامة؛ في الخاص ستتجاوز حصة 2000 دقيقة شهرياً بهذه الوتيرة).
6. من *Settings ← Secrets and variables ← Actions* أضف:
   `TELEGRAM_BOT_TOKEN` ، `TELEGRAM_ADMIN_ID` ، `GEMINI_API_KEY` ، (اختياري) `GROQ_API_KEY`
7. عدّل `config/settings.yaml`: ضع `channel.id` (مثل `@my_channel`) والمنطقة الزمنية.
8. *Actions ← news-bot ← Run workflow* للتجربة الأولى. أرسل `/preview` لبوتك لترى معاينة دون نشر.

## التجربة محلياً دون نشر

```bash
pip install -r requirements.txt
python -m unittest discover -s tests -v          # اختبارات المنطق (بلا شبكة)
export GEMINI_API_KEY=... STATE_DIR=/tmp/nb
DRY_RUN=1 python -m src.main                     # يطبع الرسائل بدل إرسالها
```

## أوامر Telegram (في محادثة البوت الخاصة، للأدمن فقط)

| الأمر | الوظيفة |
|---|---|
| `/status` | الحالة، دفعات اليوم، النسب المحددة والفعلية |
| `/ratio 50 30 20` أو `/ratio politics=60 economy=25` | نسب سياسة/اقتصاد/تكنولوجيا (تُطبَّع إلى 100) |
| `/ratio scope daily\|batch` | النسبة على اليوم كله أو في كل دفعة |
| `/ratio mode ratio\|weight` | حصص بالنسبة، أو ترتيب بالصدى فقط |
| `/batches 7` | إجمالي الدفعات (تشمل الموجز) موزعة بالتساوي |
| `/times 08:00 12:00 18:00` | مواعيد الدفعات العادية |
| `/digest 23:00` | موعد الموجز |
| `/perbatch 4` | عدد الأخبار في كل دفعة |
| `/other on\|off` | السماح بمجالات أخرى (الافتراضي: الثلاثة فقط) |
| `/source list\|add <url> [اسم]\|remove <id>` | إدارة المصادر |
| `/pause` `/resume` `/skip` `/preview` `/reset` | تحكم سريع |

الأوامر تُنفَّذ في الدورة التالية (حتى 10 دقائق). تُحفظ كتجاوزات فوق `settings.yaml`، و`/reset` تلغيها.

## التخصيص العميق (ملفات)

- `config/settings.yaml`: الجدولة، النسب، أوزان الصدى، عتبات العاجل، عتبات التشابه، الأسلوب.
- `config/sources.yaml`: المصادر وجودتها (`weight`) وهل هي موثوقة (`trusted`).
- `prompts/*.txt`: تعليمات التصنيف والصياغة العربية (غيّر النبرة والأسلوب من هنا).

## ملاحظات مهمة

- **أسماء النماذج وحدود الطبقات المجانية تتغير**: راجع `llm.providers` و`embeddings.model` في `settings.yaml` إن ظهرت أخطاء 404 في السجلات.
- **عتبة التشابه** (`dedupe.similarity_gemini`): إن ظهرت أخبار مكررة اخفضها قليلاً، وإن اندمجت أخبار مختلفة ارفعها.
- **الفحص الآلي** يرفض أي صياغة فيها أرقام غير موجودة في المصادر، أو تتجاوز الطول، أو ليست عربية. ويُسقَط الخبر إن فشل بعد إعادتين.
- **حقوق النشر**: الصياغة إعادة كتابة للوقائع مع ذكر المصدر ورابطه، ولا تنسخ النص الأصلي.
- **تأخير GitHub Actions**: الجدولة غير دقيقة بالدقيقة، وقد تتأخر الدفعة بضع دقائق (المهلة `grace_minutes`). وقد تُعطَّل الجدولة تلقائياً بعد 60 يوماً بلا نشاط في المستودع؛ أعد تفعيلها من تبويب Actions إن حدث.
- **الحالة** تُحفظ في فرع `state` بنسخة واحدة دائماً (لا يتضخم المستودع).
- النشر مباشر بلا مراجعة: راقب القناة في الأسبوع الأول، واستعمل `/pause` عند أي خلل.
- رويترز وAP عبر بحث Google News غير الرسمي، وقد يتوقف يوماً ما؛ استبدله بمصادر أخرى عند الحاجة.
